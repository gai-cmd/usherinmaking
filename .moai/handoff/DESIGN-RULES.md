# usherinmaking 리뉴얼 — 프로젝트 규칙

## 브랜드
- 표기는 한 단어 **usherinmaking** (띄어쓰기 없음). 헤더·푸터·OG는 텍스트가 아니라 **로고 이미지(SVG)**.
- 드레스 브랜드명 없음. DRESS 페이지는 컬렉션만.
- 작가명 = usherinmaking.

## 구조
- 2대 축: **LOCATION(실외)** / **STUDIO(실내)** — 완전 분리. 우천 대안 문구 없음.
- LOCATION은 **지역이 아니라 촬영 카테고리** 기준: WEDDING(前撮り·後撮り·セルフ) / ANNIVERSARY(家族·七五三·マタニティ·デート·記念日) + 월별 아카이브.
- STUDIO 세트 4개: アーチ窓・自然光 / ドレスルーム / ヴィンテージ コーナー / モノトーン コーナー. (「한옥풍」 아님 — 화이트 스타코 + 헤링본 + 브라스 + 아치)
- **자동예약·캘린더 예약 기능 없음.** 문의 → 상담으로만 확정.
- RESERVE 페이지 없음 → 그 자리에 PHOTOGRAPHER.

## 언어와 상담 채널
- 언어: 日本語(기본) / English / 한국어 — 기기(브라우저) 언어 자동 감지 + 수동 전환, /ja /en /ko + hreflang.
- 상담 SNS: **한국어 = 카카오톡**, **일본어 = LINE(네이버 라인)**, **영어 = 이메일**.
- 공통: **문의 폼 + 이메일**.
- 한국어 페이지에는 **네이버 블로그 연계 안내**를 넣는다 (일본어·영어 페이지에는 넣지 않음).

## 사진
- 인스타 @usherinmaking 게시물을 **전량 자동 수집** → AI 카테고리·alt 추천 → **관리자가 전시할 것만 선택** → 프론트 노출.
- 인스타 임베드·아웃링크 사용 안 함. 원본은 자사 스토리지, 사이트는 AVIF/WebP 다중 사이즈로 재인코딩.
- 시안에서는 `img/s/*.png`(560px 축소본)를 참조 — 원본은 `uploads/`.

## 사실 확인 규칙
- 근거 없는 수치·사실을 단정하지 말 것. 미확정 정보는 「（要確認）」/「(to be confirmed)」로 표기.
- 확정된 사실: 주차 2대, 평수 표기 없음, 스튜디오 플랜(¥99,000 / ¥150,000 / ¥66,000 / ¥25,000, 모니터 가격), 로케이션 플랜(¥76,000 / ¥100,000 / ¥128,000 税込), 기념사진(¥38,000 / ¥60,000 税込).
- 税込 표기는 로케이션·기념사진에만 (스튜디오 플랜은 근거 없음).

## 디자인

- 서체: JA = Zen Old Mincho + Zen Kaku Gothic New, 라틴 = Cormorant Garamond(제목) + Jost(본문·라벨). EN 페이지 본문은 명조 대신 Jost.
- 아치를 브랜드 모티프로 (이미지 상단 라운드).
- 모바일 탭 타겟 44px 이상. 영문 페이지에 일본식 문장부호(・ ／ 〜 전각공백) 금지.
