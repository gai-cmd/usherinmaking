# 질문형 콘텐츠 기획 — 검색·AI 답변 노출 → 문의 전환

작성 2026-08-25. 근거: awesome-geo(Google·OpenAI·Perplexity·Anthropic 공식 문서의 공통분모 — 크롤 가능·신뢰 가능·최신·질문에 답하는 페이지). AI 전용 트릭 없음.

## 왜 질문형인가
- 검색·AI 엔진은 "질문 → 명확한 답 → 근거" 구조의 페이지를 인용한다. 사진만 있는 후기는 인용될 문장이 없다.
- 예약 직전 단계의 사람이 치는 질문(비용·시기·비·드레스)에 답하면 유입이 곧 문의로 이어진다.
- 각 글 끝에 플랜·문의 링크(CTA) 를 두어 유입이 새지 않게 한다.

## 발행 위치와 형식
- 위치: 촬영후기(journal)의 `tips` 카테고리 — 이미 존재하고 사이트맵·BlogPosting 구조화 데이터가 붙는다. 새 라우트 불필요.
- 형식: 제목은 질문 그대로 / 첫 문단에 두 문장 요약 답 / 소제목(H2)로 세부 / 표는 가격·시간처럼 비교할 것만 / 마지막 "문의하기" 링크.
- 구조화 데이터: 글 안의 Q&A 블록에 `FAQPage` 를 추가하는 렌더러 지원이 필요(현재 BlogPosting 만). — 코드 작업 1건.
- 갱신일 표기: 가격·정책 글은 본문에 "2026-08 기준" 을 명시하고 바뀔 때 갱신.
- 언어: 한국어 먼저(후기 채널이 한국어), 반응 있는 글부터 일본어·영어 확장.

## 먼저 바로잡을 불일치 (AEO 신뢰 신호)
- 문의 FAQ 는 "웨딩 88만원부터, 기타 30만원부터"(원화), 플랜 페이지는 ¥76,000~¥150,000(엔화). 같은 사이트에서 가격 단위·수치가 다르면 엔진이 어느 쪽도 인용하지 않는다. → 플랜 페이지 값을 기준으로 FAQ 를 엔화(+원화 환산 안내) 로 통일.
